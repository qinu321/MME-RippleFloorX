RippleFloorX ver 1.1
======================================================================

【这一版改了什么】

  0.1 是「随脚高变化的光环」，脚抬起来环就外滑、变大、变淡，
  那是我按 WF_XxShadow 的高度投影思路做的，所以你看到的「方向偏了」。

  0.2 改回你要的老行为：

    脚一接触地面  ->  记下落点和一个时间戳，插到队列最前面
    之后不管脚抬多高 ->  涟漪从落点自己扩散，持续 5 秒
    再踩一次      ->  再插入一个新涟漪，旧的整体后移，不会覆盖
    队列 24 个槽位  ->  最多同时存在 24 个涟漪（5 秒内一般踩不出这么多）

  1.0 修「播放时整段不出涟漪」：触发从「跟最新那笔涟漪比位置」改成
      落地沿（上一帧不踩、这一帧踩 = 新的一步）。位置规则看不出原地跺脚，
      参考点一卡住就永久静默。

  1.1 修「播放中站着不动会自己冒涟漪」：1.0 的落地沿是拿二值接触标志做的，
      身体 idle 摆动时脚底高度会在接触阈值上下抖，每抖出一个「沿」就冒一下。
      现在改成带迟滞的踩住标志 + 滞空时间：

        - 踩住是**锁定**的：脚要抬到 LIFT_H（0.35 × 小腿长）以上才算"离地"，
          落回 CONTACT_H（0.20）以下才算"踩住"。中间那一圈抖动不会翻状态，
          所以静止摆身体不冒涟漪。
        - 还要滞空 MIN_AIR（0.10 秒）以上，一两帧的抖动直接滤掉。
        - 子效果现在**只要有脚骨就每帧写标记**（不只踩地时写），
          因为地板需要知道离地高度才能做上面这套迟滞。


【怎么做的（为什么不用写模型名）】

  和 0.1 一样，靠离屏自动挂载：
    地板 .fx 声明 OFFSCREENRENDERTARGET，DefaultEffect 把 *.pmd/*.pmx
    指向 RF_FootRipple.fxsub。每个模型自动拿到这个子效果，换模型不用改文件。

  分工：

    子效果（每个模型）：每帧往离屏缓冲底部写一个 4x4 像素的小块，
      颜色 = (地板局部 x, 地板局部 z, 鞋底高度 ÷ 小腿长, 1)。
      缓冲是浮点格式，所以数值是精确的，没有编码/解码、没有量化。
      没有足首/ひざ/つま先 骨骼的对象（比如控制器模型）不写。

    地板自己：每帧读这 8 个脚位，用迟滞判定"这一帧是不是真的一步落地"，
      是就把 (x, z, 时间) 插到队首，然后在地板平面上画队列里的环。

  状态纹理是两张 1x32 的 RGBA32F 做双缓冲（A 写本帧、B 存本帧副本，
  下一帧所有读取都走 B）。前 8 行是脚位，后 24 行是涟漪队列：

    行 0-7   脚位：（踩住没, 上次生成涟漪的时间, 离地时刻, -）
    行 8-31  涟漪：（x, z, 开始时间, 1 + 图案编号）

  脚位那行每帧都重写，所以"上一帧踩住没""什么时候离地"都能跨帧读；
  因此不需要 TEXTUREVALUE（那个在本机读回不可靠，1x64 时后 32 行直接是 0）。

  接触标记的槽位：slot = (VertexCount * 2 + 左/右) % 8，
  也就是 8 个「脚位」（最多 4 个模型）。

  涟漪是另一份 24 槽队列：新涟漪插到队首，旧的整体后移，
  超过 5 秒的自动失效。所以连续走会叠出一串不同半径的环，
  不会互相覆盖。


【文件】

  RippleFloorX.x        地板配件（20×20 平面，y=0）
  RippleFloorX.fx       地板本体：读标记、记状态、画涟漪
  RF_FootRipple.fxsub   每个模型的「接触报告器」（自动挂，Shift-JIS）
  RF_FootRing.fxsub     0.1 那版的脚环，留着当退路（见下）

  四个文件放同一个文件夹。载入 RippleFloorX.x 即可（MME 0.33+）。

  ★ .fx 和 .fxsub 必须是一对的（1.0 起两边共用新的标记格式，
    1.1 又把标记的第三通道改成高度）。只换其中一个会读到旧格式。


【使用】

  1. 载入 RippleFloorX.x，Y 设成地板高度 +0.1 左右。
  2. 拖模型进去：脚落地时出涟漪，5 秒内扩散完。
  3. 颜色/亮度：MMEffect → 效果参数里的 Ripple Color / Ripple Strength。
  4. 配件 Tr 仍然可以整体调透明度。


【调参（RippleFloorX.fx 顶部）】

  RIP_MAX      5.0    涟漪寿命（秒）
  RIP_RADIUS   16.0   寿命结束时的半径（地板局部单位）
  RIP_BAND     0.04   三角/方/圆的线条粗细（半径的比例）
  RIP_LINE_W   0.15   线图案的线宽（局部单位）
  RIP_ROT      4.0    三角/方的旋转速度（弧度/秒）
  SLOT_COUNT   24     涟漪队列槽位（前 8 行是脚位，合计 32 行）
  FOOT_ROWS    8      脚位数量，必须和 RF_FootRipple.fxsub 里的 FOOT_SLOTS 一致

  CONTACT_H    0.20   鞋底高度 ÷ 小腿长 低于这个 = 踩住
  LIFT_H       0.35   要抬过这个才算"离地"（迟滞带 = 0.20~0.35）
  MIN_AIR      0.10   离地至少这么久（秒）才算一步
  TRIG_HOLD    0.50   同一只脚两次出涟漪的最小间隔（秒）
  TRIG_GAP     0.40   全局最小间隔（秒），不管哪只脚
  DEBUG_HUD    0      改成 1 = 在地板边缘画出 8 个脚位状态方块（排查用）

  RIP_RADIUS = 16，地板是 ±10，所以图案会越过地板边缘再消失（约 3 秒到边）。
  想让扩散更快/更慢改 RIP_RADIUS；地板放大（Si）时比例不变。

  【四种图案】生成时决定，并存进涟漪本身（状态行的 w = 1 + type）：
      type 0  放射线（短命，1.5 秒内淡出）
      type 1  旋转三角形
      type 2  旋转正方形
      type 3  圆

  生成公式是 floor(开始时间) + 左右脚（0/1），再对 4 取模，
  所以左右脚固定错开一位——两只脚同时落地也一定是不同图案；
  每秒换一种，连续踩会看到 4 种交替出现。

  出生 0.15 秒内淡入，越往外越淡（1 / (1 + 半径×0.22)），
  最后 1.5 秒整体淡出，叠加上限 1.6。


【触发频率 / 回放】

  一只脚要出涟漪，下面四条要同时成立：

    1. 这一帧踩住（鞋底高度 ÷ 小腿长 < CONTACT_H）；
    2. 上一帧还没踩住，而且中间是**真的抬起来过**（曾经超过 LIFT_H）
       并滞空至少 MIN_AIR；
    3. 这只脚距上次出手超过 TRIG_HOLD（0.50 秒）；
    4. 距最新一笔涟漪超过 TRIG_GAP（0.40 秒）；控制器 Freq± 缩放的就是它。

  所以：
    站着不动（含播放中的 idle 摆动）-> 踩住标志一直锁着，不冒；
    原地抬脚再踩                      -> 抬超过 LIFT_H 就解锁，落回即出环；
    走 / 跳 / 跺脚                    -> 每次落地一个，队首插入、旧的后移。

  时间轴倒带（播放从头、来回拖）时，状态里存的"将来时间"一律当成
  "很久以前"，所以第二次、第三次播放都正常。

  编辑模式（暂停）下也能实时出涟漪、实时预览颜色——时间参数用的是系统时间，
  播放时仍然跟随帧时间，出片结果不变。

  觉得太少/太多：
    - 播放中静止还冒 -> 把 LIFT_H 调大（0.35 -> 0.45），迟滞带更宽；
    - 抬脚踩下不冒   -> 把 LIFT_H 调小（0.35 -> 0.28），或 MIN_AIR 调小；
    - 整体太密/太疏  -> TRIG_GAP（全局）、TRIG_HOLD（同一只脚）。


【控制器（可选，PMX 表情）】

  载入 RippleFloorCtrl.pmx 后，可以用它的「表情」实时控制颜色和频率。
  表情名必须和下面完全一致（ASCII、区分大小写）：

    Hue+      色相顺时针，1.0 = 转一整圈
    Hue-      色相逆时针，1.0 = 转一整圈
    Bright+   变亮，1.0 = 亮度 ×3
    Bright-   变暗，1.0 = 亮度 ÷3
    Freq+     涟漪更密，1.0 = 触发间隔 ÷3
    Freq-     涟漪更疏，1.0 = 触发间隔 ×3

  全部表情都是 0 = 不改变，所以：
    - 不载入控制器 → 和现在完全一样；
    - 载入了但表情都是 0 → 也一样；
    - 只做其中几个表情也没问题（缺的读 0，等于不改变）。

  Hue± 是在「效果参数」面板里 Ripple Color 的色相上转圈，
  所以基础色仍然由面板决定。控制器模型本身可以是个很小的、
  没有材质的空模型，只要表情名对得上即可；建议留着显示状态。

  文件不在这个包里——需要自己用 PMX Editor 做（或改一个现成的），
  模型名改成 RippleFloorCtrl.pmx 放在同一目录。

【回退到 0.1 的光环】

  如果这一版有问题，把 RippleFloorX.fx 里 DefaultEffect 的
      "*.pmd = RF_FootRipple.fxsub;"
      "*.pmx = RF_FootRipple.fxsub;"
  改成
      "*.pmd = RF_FootRing.fxsub;"
      "*.pmx = RF_FootRing.fxsub;"
  就回到「脚高驱动」的那版（已验证能出环）。
  注意 0.1 的 fxsub 是给 0.1 的 fx 用的；换回时 fx 里多出来的状态 pass
  不会执行（DefaultEffect 不引用它们），不影响。


【已知限制 / 取舍】

  - 槽位用 VertexCount 当模型 ID。两个模型顶点数相同（尤其是同一个模型
    加载两份）会撞槽，可能互相覆盖涟漪。8 个脚位够 4 个模型。
  - 触发依赖材质 0 参与渲染（照抄 XxShadow 的 Subset="0"）。
    如果某个模型完全没反应，先换 Subset 编号试试。
  - 骨骼用标准名（右足首/左足首/右ひざ/左ひざ/右つま先/左つま先）。
    非人型或改过骨名的模型不触发。
  - 子效果只写标记，不画东西；所以地板本体（.fx）必须活着——
    地板被隐藏/不渲染时，状态不会更新。
  - 迟滞阈值是按「鞋底高度 ÷ 小腿长」归一化的，所以模型高矮不影响；
    但极端比例的模型（鞋底骨骼离地很高）可能需要微调 CONTACT_H。
  - .fx / .fxsub 都是 Shift-JIS，改的时候别存成 UTF-8。


【排查】

  1. 完全没有：MME 版本；效果割当里 RippleFloorX 是否在、模型是否挂了
     RF_FootRipple；地板 Y 是否和模型站的平面一致。
  2. 想直接看判定：把 RippleFloorX.fx 顶部的 DEBUG_HUD 改成 1，重载地板，
     地板靠近 -Z 的那条边会出现 8 个方块（每个脚位一个）：
        暗红 = 这个脚位没有骨骼数据（模型没挂上 / 骨名不对 / Subset 不对）
        黑   = 有数据，但脚这一帧不在 LIFT_H 以下
        蓝   = 上一帧是踩住的（已解锁中）
        绿   = 这一帧踩住
        洋红 = 这一帧要出涟漪
     方块全暗红 -> 标记链断了，查 fxsub 挂载与骨名；
     一直绿、从不蓝 -> 一直踩住，正常（静止就是这状态）；
     绿蓝来回跳但不该跳 -> LIFT_H 偏小，调大。
  3. 有环但位置偏：环心是踝骨在地板上的投影，脚背长的模型会偏一点；
     检查地板 Y / Si。
  4. 环太大/太小/太快：RIP_SPEED / RIP_RADIUS / RIP_MAX。
  5. 播放到片尾停住/只在开头出一次：那是时间轴行为，正常（见上「回放」）。
