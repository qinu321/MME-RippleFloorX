RippleFloorX ver 1.0
======================================================================

【这一版是什么】

  脚踩地出涟漪、涟漪自己扩散 5 秒后消失、连续走会叠出一串不同半径的环。
  不写死模型名：地板 .fx 声明离屏渲染目标，DefaultEffect 把 *.pmd/*.pmx
  都指向 RF_FootRipple.fxsub，换模型不用改文件。

  历史：0.1 是「随脚高变化的光环」（方向不对，废弃）→ 0.2 改回落点队列 →
  1.0 触发改成落地沿 + 浮点标记（详细改动看 git log；本仓库从 1.0 起纳入版本管理）。


【文件】

  RippleFloorX.x        地板配件（20×20 平面，y=0）
  RippleFloorX.fx       地板本体：读标记、记状态、画涟漪
  RF_FootRipple.fxsub   每个模型的「脚部报告器」（自动挂，Shift-JIS）
  RF_FootRing.fxsub     0.1 那版的脚环，留着当退路（见下）

  四个文件放同一个文件夹。载入 RippleFloorX.x 即可（MME 0.33+）。

  ★ .fx 与 .fxsub 必须同版：标记格式是两边共用的约定。
    只换其中一个 = 另一边按旧格式读，行为不可预料。


【怎么做的】

  子效果（每个模型）：只在**脚踩地时**往离屏缓冲底部写一个 4x4 像素小块，
    颜色 = (地板局部 x, 地板局部 z, 0, 1)。缓冲是浮点格式，坐标精确无量化。
    不在接触中就把方块收缩成零点，不写任何东西。

  地板自己：每帧读这 8 个脚位（槽位 slot = (VertexCount*2 + 左/右) % 8，
    8 个脚位够 4 个模型），配合上一帧状态判断"这一帧是不是新落地"，
    是就把 (x, z, 时间) 插到队首，然后在地板平面上画队列里的环。

  状态纹理：两张 1x32 的 RGBA32F 双缓冲（A 写本帧、B 存本帧副本，下一帧
  所有读取都走 B，不用 TEXTUREVALUE——那个在本机 1x64 时后 32 行读回是 0）：

    行 0-7   脚位：（这一帧踩没踩, 上次生成涟漪的时间, 落点 x, 落点 z）
    行 8-31  涟漪：（x, z, 开始时间, 1 + 图案编号）


【使用】

  1. 载入 RippleFloorX.x，Y 设成地板高度 +0.1 左右。
  2. 拖模型进去：脚落地时出涟漪，5 秒内扩散完。
  3. 颜色/亮度：MMEffect → 效果参数里的 Ripple Color / Ripple Strength。
  4. 配件 Tr 仍然可以整体调透明度。


【调参】

  RippleFloorX.fx 顶部：
    RIP_MAX      5.0    涟漪寿命（秒）
    RIP_RADIUS   16.0   寿命结束时的半径（地板局部单位，地板是 ±10）
    RIP_BAND     0.04   三角/方/圆的线条粗细（半径的比例）
    RIP_LINE_W   0.15   线图案的线宽（局部单位）
    RIP_ROT      4.0    三角/方的旋转速度（弧度/秒）
    SLOT_COUNT   24     涟漪队列槽位（前 8 行是脚位，合计 32 行）
    FOOT_ROWS    8      脚位数量，要和 fxsub 的 FOOT_SLOTS 一致
    TRIG_HOLD    0.50   同一只脚两次出涟漪的最小间隔（秒）
    TRIG_GAP     0.40   全局最小间隔（秒），不管哪只脚
    STEP_R       2.0    落点比这只脚上次落地挪多少算"新的一步"（局部单位）
    DEBUG_HUD    0      改成 1 = 地板 -Z 边画 8 个脚位状态方块（排查用）

  RF_FootRipple.fxsub 顶部：
    CONTACT_RATE 0.20   鞋底高度 / 小腿长 低于这个算踩住（0.10 更灵敏、涟漪更多；
                        0.25 更迟钝、更少）
    FOOT_THICK   0.22   踝骨到鞋底的高度（× 小腿长），接触判定用

  控制器（可选，RippleFloorCtrl.pmx 的表情）：Hue± 转色相、Bright± 调亮度、
  Freq± 缩放 TRIG_GAP。全 0 = 不改变，所以不载入控制器也完全一样。
  表情名必须完全一致（ASCII、区分大小写）。


【触发规则（1.0）】

  一只脚出涟漪，要同时成立：

    1. 这一帧踩住（鞋底高度 < CONTACT_RATE × 小腿长）；
    2. 上一帧没踩住（落地沿），**或者**落点比这只脚上次落地挪过 STEP_R；
    3. 这只脚距上次出手超过 TRIG_HOLD；
    4. 距最新一笔涟漪超过 TRIG_GAP（控制器 Freq± 缩放这一条）。

  两条 2 是"或"，只可能多出涟漪、不会互相堵死。

  时间轴倒带（播放从头、来回拖）时，状态里存的"将来时间"一律当"很久以前"。

  编辑模式（暂停）也能实时出涟漪——时间参数用系统时间，播放时跟随帧时间。


【已知问题 / 限制】

  - **播放中站着不动时涟漪仍会自己冒**（身体 idle 摆动让接触标志在阈值处抖动，
    每个抖动都被当成一次落地）。1.0 用二值接触沿，没做滤波。
    已经试过并回退的方案：v1.1「迟滞踩住 + 滞空时间」（git tag v1.1-latch）——
    反而让 0 帧静止也开始冒，原因未定位，已回退。
  - 槽位用 VertexCount 当模型 ID。顶点数相同的两个模型会撞槽（同一个模型
    加载两份尤其明显），可能互相覆盖涟漪。
  - 触发依赖材质 0 参与渲染（照抄 XxShadow 的 Subset="0"）。
  - 骨骼用标准名（右足首/左足首/右ひざ/左ひざ/右つま先/左つま先）。
  - 子效果只写标记，不画东西；地板被隐藏/不渲染时状态不更新。
  - .fx / .fxsub 是 Shift-JIS(CP932) + LF，改的时候别存成 UTF-8、别让 git
    动换行（本目录的 .gitattributes 已写 `* -text`）。


【排查】

  1. 完全没有：MME 版本；效果割当里 RippleFloorX 在不在、模型有没有挂
     RF_FootRipple；地板 Y 是否和模型站的平面一致。
  2. 看判定：DEBUG_HUD 改 1 重载地板，-Z 边出现 8 个方块：
        黑 = 这只脚这一帧不在地板上；蓝 = 上一帧踩过；绿 = 这一帧在踩；
        洋红 = 这一帧要出涟漪。全黑 = 标记链断了（查 fxsub 挂载/骨名/Subset）。
  3. 有环但位置偏：环心是踝骨在地板上的投影，脚背长的模型会偏一点。
  4. 环太大/太小/太快：RIP_SPEED / RIP_RADIUS / RIP_MAX。


【回退到 0.1 的光环】

  把 RippleFloorX.fx 里 DefaultEffect 的
      "*.pmd = RF_FootRipple.fxsub;"  "*.pmx = RF_FootRipple.fxsub;"
  改成 RF_FootRing.fxsub，就回到「脚高驱动」那版（已验证能出环）。


【版本管理】

  本目录已 git 管理：
    git tag v1.0-work     当前状态（可用）
    git tag v1.1-latch    v1.1 实验版（迟滞，已回退）
    git diff v1.0-work v1.1-latch    看 1.0 → 1.1 到底改了什么
    git checkout v1.1-latch -- RippleFloorX.fx RF_FootRipple.fxsub   取回实验版
    git checkout v1.0-work -- .                                    回到可用版
  注意 *.bak* 与 *.fxo 在 .gitignore 里，不进库（历史用 git 看）。
