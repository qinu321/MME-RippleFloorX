RippleFloorX ver 3.8
======================================================================

【概要】

  足が床に着くと、その場所から波紋が広がり、約 5 秒かけて消えます。
  歩いたり跳んだりすれば着地点ごとに波紋が生まれ、半径の違う輪が幾重にも重なります。
  立ち止まっているとき（モーション再生中の軽い揺れも含む）は何も出ません。
  模様は 5 種類（放射状の線／三角形／四角形／円／星形）が順番に切り替わります。

  モデル名を埋め込んでいないので、キャラクターを差し替えてもファイルを編集する必要はありません。
  備考：本 MME は、舞力介入P の「Innocencer」を改造したものです。元版では .fx ファイルを編集してモデル名を手で書き加える必要があり、これが最大の手間でした。針金P の「WorkingFloorX」と ikeno の「WF_XxShadow」を参考に、ファイルを編集せずモデルを読み込む（ドラッグする）だけで使えるよう、特定のモデルに縛られない形に改めました。あわせて星形の模様と、波紋を調整できるコントローラーを追加しています。

【ファイル】

  RippleFloorX.x        床アクセサリ（20×20 の平面、y=0）  ← これを読み込みます
  RippleFloorX.fx       エフェクト本体
  RF_FootRipple.fxsub   各モデルの足元を報告するサブエフェクト（自動で割り当てられます）
  RippleFloorCtrl.pmx   パラメータ制御用モデル（任意）

  readme_en.txt / readme_jp.txt   本書の英語版／日本語版

  4 つのファイルを同じフォルダに置いてください（MMEffect 0.33 以降）。
  ★ .fx と .fxsub は同じ版で揃えてください。両者はマーカー形式を共有しています。

  仕組み・全パラメータ・デバッグ方法・ビルド手順は docs\TECH.txt（中国語）に
  まとめてあります。通常の使用では読む必要はありません。

【使い方】

  1. 暗めの床モデルを先に読み込み、そのあとキャラクターモデルを読み込みます。
  2. RippleFloorX.x を読み込み、アクセサリの編集画面で数値を調整します。
     Y は床の高さ +0.1 程度に。Si で床の大きさ、Tr で全体の透明度を変えられます。
  3. 「背景」→「アクセサリ編集」で、RippleFloorX.x が床モデルより後に描画される
     ようにしてください（よく分からなければ数値を 0 に）。続いて MMEffect の
     「エフェクト割当」で、RippleFloorX.x が床モデルより下に来るように並べます。
  4. 色・大きさ・間隔を変えたいときは RippleFloorCtrl.pmx も読み込みます
     （表示はオフにして構いません）。
  5. キャラクターの足 IK を上げ下げしてみて、波紋が出れば成功です。
  6. .fx を書き換えたあとは、MMD を再起動するか床アクセサリを読み込み直してください
     （MME は .fx を自動で再コンパイルしません）。

  キャラクターモデルは 8 体まで対応しています。多人数で使うときは Freq- を
  0.4〜0.5 程度まで上げてください（下の表を参照）。そのままだと輪同士が押し合って、
  出たり消えたりが目立つようになります。

【制御用の表情（モーフ） — RippleFloorCtrl.pmx・任意】

  どの表情も 0 が基準です。コントローラを読み込まない場合や、読み込んでも
  表情を動かしていない場合は、既定の見た目とまったく同じになります。
  表情名は完全一致で判定されます（ASCII・大文字と小文字を区別）。

    Hue+ / Hue-        色相（時計回り／反時計回り）。1.0 で 1 周
    Bright+ / Bright-  明るさ ×3 ／ ÷3
    Freq+ / Freq-      モデルごとの波紋の間隔：0.40 秒 → 0.13 秒（密）／ 5.2 秒（疎）
    Life+ / Life-      波紋の寿命：5 秒 → 15 秒（長く・大きく）／ 1.7 秒（短く・小さく）
    Step+ / Step-      滑り判定のしきい値：×3 で大きな歩みのみ ／
                       ÷3 でわずかな滑りも 1 歩とみなす
    TriSz+ / TriSz-    三角形の大きさ：最大 2.5× ／ 0.4×
    SqrSz+ / SqrSz-    四角形の大きさ：同上
    CirSz+ / CirSz-    円の大きさ：同上
    StarSz+ / StarSz-  星形の大きさ：同上
    LineSz+ / LineSz-  放射状の線の幅：同上
    Jitter             波紋ごとの大きさのばらつき：0 で無効、最大で 1 つごとに ±25%
    Rot+ / Rot-        模様の回転速度：4.0 rad/s → 10.0（速く）／ 1.6（遅く）

  ● 調整のコツ

  ・同じ模様の + と - は同時に引いても構いません。倍率は (1 + 1.5×P) / (1 + 1.5×M) で、
    両方を 1.0 にすると 1.0 倍に戻ります（中央に戻すときに便利です）。
  ・5 種類の大きさを変えたいときは、いくつかの Sz± に別々の値を入れてください。
    1 つ 1 つの波紋の大きさを変えたいときは Jitter を上げます
    （見た目の大きさだけが変わり、波紋が出る頻度には影響しません）。
  ・5〜8 体で使うときは Freq- を 0.25 以上（間隔 1.6 秒）に。0.4〜0.5 くらいが扱いやすいです。
  ・Life+ を上げるとキューが早く埋まり、古い輪から捨てられます。
    「長く、かつたくさん」にしたいときは Freq- も合わせて上げてください。
  ・Rot± が効くのは三角形・四角形・星形だけです（円と放射状の線は回しても見た目が変わりません）。
  ・表情にはキーフレームを登録できます。たとえば 1000 フレームごとに Hue+ を
    登録しておけば、色が時間とともに変わる模様になります。
  ・アクセサリパネルの「加算」で見た目を切り替えられます。オンにすると暗い床で
    波紋が光ります（グロー）。オフにすると床は透明になり、模様は実色の線で
    描かれるので、白い床でもはっきり見えます。

【うまくいかないとき】

  1. 何も出ない
     ・MME のバージョンが 0.33 以降か確認してください。
     ・「エフェクト割当」に RippleFloorX があるか、キャラクターに RF_FootRipple が
       割り当てられているか確認してください。
     ・床の Y がキャラクターの立っている面と一致しているか確認してください
       （少しのズレでも出ません）。

  2. 波紋は出るが中心がずれる
     ・中心は足首を床に投影した点なので、足の甲が長いモデルでは少しずれます。仕様です。

  3. 大きすぎる／小さすぎる／速すぎる
     ・まず Life± と Sz± の表情で調整してください。根本の数値は docs\TECH.txt の
       RIP_RADIUS / RIP_MAX を参照してください。

  4. 多人数で出たり出なかったりする
     ・キューが飽和しています。Freq- を上げてください（0.25 以上）。

  5. 設定を変えても反映されない
     ・MME は .fx を自動で再コンパイルしません。MMD を再起動するか、
       アクセサリを読み込み直してください。
     ・それでも変わらないときは、.fx 冒頭の DEBUG_HUD を 1 にしてデバッグ用の帯を
       表示してください（帯の意味は docs\TECH.txt にあります）。
