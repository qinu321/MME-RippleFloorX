RippleFloorX ver 3.6
======================================================================

【これは何をするか】

  足が床に着く → その場所に波紋の輪が生まれ、約 5 秒かけて広がって消えます。
  歩く／跳ぶ → 着地点ごとに 1 つずつ、半径の違う輪が連なります。
  立ち止まっている（モーション再生中の idle の揺れも含む）→ 何も出ません。
  図柄は 5 種類が順番に出ます：放射線／三角形／正方形／円／五芒星。

  モデル名は一切埋め込んでいないので、キャラを差し替えてもファイル編集は不要です。

【ファイル】

  RippleFloorX.x        床アクセサリ（20×20 平面、y=0）  ← これを読み込む
  RippleFloorX.fx       エフェクト本体
  RF_FootRipple.fxsub   各モデルの足元レポーター（自動で割り当て）
  RippleFloorCtrl.pmx   パラメータ制御用（任意）

  readme_en.txt / readme_jp.txt   本書の英語版／日本語版

  4 ファイルを同じフォルダに置いてください（MMEffect 0.33 以降）。
  ★ .fx と .fxsub は同じ版で揃えてください（マーカー形式を共有しています）。

  仕組み・全パラメータ・デバッグ・ビルド手順は docs\TECH.txt（中国語）に
  まとめてあります。通常の使用では読む必要はありません。

【使い方】

  1. まず暗めの床モデルを読み込み（推奨）、そのあとキャラクターモデルを入れます。
  2. RippleFloorX.x を読み込み、アクセサリパネルで値を調整します。
     Y は床の高さ +0.1 程度、Si で床の大きさ、Tr で全体の透明度を変えられます。
  3. 背景 - アクセサリ編集 で、RippleFloorX.x が床モデルより後に描かれるように
     してください（分からなければ数値を 0 に）。さらに MMEffect のエフェクト割当で
     RippleFloorX.x が床モデルより下に来るようにします。
  4. 色／大きさ／間隔を変えたいときは RippleFloorCtrl.pmx も読み込みます
     （表示はオフにして構いません）。
  5. キャラの足 IK を上げ下げして、波紋が出れば成功です。
  6. .fx を書き換えたら MMD の再起動か床アクセサリの再読み込みが必要です
     （MME はホットリコンパイルしません）。

  キャラクターモデルは最大 8 体まで。多人数のときは Freq- を 0.4〜0.5 程度に
  上げてください（下記参照）。そのままだと輪同士が押し出し合って、
  出たり消えたりが不規則になります。

【制御用モーフ（RippleFloorCtrl.pmx、任意）】

  すべて 0 = 変化なし：コントローラを読み込まない場合、または読み込んでも
  モーフが 0 の場合は、既定の見た目と完全に同じです。
  モーフ名は完全一致（ASCII・大文字小文字を区別）。

    Hue+ / Hue-        色相 時計回り／反時計回り、1.0 で 1 周
    Bright+ / Bright-  明るさ ×3 ／ ÷3
    Freq+ / Freq-      モデルごとの発生間隔：0.40 秒 → 0.13 秒（密）／ 5.2 秒（疎）
    Life+ / Life-      波紋の寿命：5 秒 → 15 秒（長く大きく）／ 1.7 秒
    Step+ / Step-      滑り判定のしきい値：×3 で大きな歩みのみ ／ ÷3 でわずかな滑りも
    TriSz+ / TriSz-    三角形の大きさ：最大 2.5× ／ 0.4×
    SqrSz+ / SqrSz-    正方形の大きさ：同上
    CirSz+ / CirSz-    円の大きさ：同上
    StarSz+ / StarSz-  五芒星の大きさ：同上
    LineSz+ / LineSz-  放射線の線幅：同上
    Jitter             波紋ごとの大きさのゆらぎ：0 = なし、最大で 1 輪ごとに ±25%
    Rot+ / Rot-        図柄の回転速度：4.0 rad/s → 10.0（速く）／ 1.6（遅く）

  補足：

  · 同じ図柄の + と - は同時に引けます。倍率 = (1 + 1.5·P) / (1 + 1.5·M) で、
    両方 1.0 にすると 1.0 倍に戻ります。
  · 5 種類の大きさを変えたい → いくつかの Sz± に値を入れる。
    1 輪ごとに変えたい → Jitter を上げる（見た目の大きさだけが変わり、
    発生頻度には影響しません）。
  · 5〜8 体のときは Freq- を 0.25 以上（間隔 1.6 秒）に。0.4〜0.5 が快適です。
  · Life+ を上げるとキューが早く埋まり、古い輪から捨てられます。
    「長く、かつ多く」にしたいときは Freq- も併せて上げてください。
  · Rot± が見た目に効くのは 三角形／正方形／五芒星 だけです
    （円と放射線は回転しても見た目が変わりません）。

【トラブルシューティング】

  1. まったく出ない
     · MME のバージョンが 0.33 以降か
     · エフェクト割当に RippleFloorX があるか、キャラに RF_FootRipple が
       割り当てられているか
     · 床の Y がキャラの立っている面と一致しているか（少しのズレでも出ません）

  2. 出るが中心がズレる
     · 中心は足首を床に投影した点なので、足の甲が長いモデルは少しズレます（正常）

  3. 大きすぎる／小さすぎる／速すぎる
     · まず Life± と *Sz± で調整。根本の数値は docs\TECH.txt の
       RIP_RADIUS / RIP_MAX を参照

  4. 多人数で出たり出なかったりする
     · キューが飽和しています。Freq- を上げてください（0.25 以上）

  5. 変化が見えない
     · MME は .fx をホットリコンパイルしません。MMD の再起動かアクセサリ再読み込み
     · それでも駄目なら .fx 冒頭の DEBUG_HUD を 1 にしてデバッグ帯を確認
       （意味は docs\TECH.txt）
